# Getting Started

Welcome to the **EUV Defines Editor** — a browser-based tool for creating gameplay modifier mods for Europa Universalis V, no file editing required.

---

## What Are Defines?

In EU5, **defines** are constants that control hundreds of gameplay behaviors — combat damage, economy growth rates, AI decision thresholds, diplomacy costs, and much more. Normally, modding these requires editing Paradox script files by hand and setting up a mod folder structure yourself.

This editor removes that barrier: you see a clean form, change the values you want, and download a ready-to-use mod.

---

## Prerequisites

| Requirement | Details |
|---|---|
| **Web browser** | Any modern browser — Chrome, Firefox, Edge, or Safari |
| **EU5** | A copy of Europa Universalis V (needed to use the exported mod) |
| **Installation** | None — everything runs in your browser, no sign-up required |

---

## Quick Start

Follow these six steps to go from zero to a working mod:

1. **Open the Editor** — Click **Editor** in the left sidebar.
2. **Select a game version** — Click the **Version** button at the bottom of the left sidebar. Choose the version that matches your EU5 installation.
3. **Create a project** — Click the project name in the top bar to open the Project Selection dialog, then click **+ Create new project**. Give it a descriptive name (e.g., `my-economy-overhaul`).
4. **Find defines** — Use the **search bar** to look up defines by name, or browse categories in the **right sidebar**.
5. **Edit values** — Click any input field and type a new value. Modified fields are highlighted with a **gold border**.
6. **Export your mod** — Click the **export button** (⇩) in the bottom bar to download a ready-to-use `.zip` file.

> **Tip:** Changing the game version later will reset your changes, so make sure you pick the right one before you start editing.

---

## Your Data Stays Local

All projects and changes are saved **automatically** in your browser's local storage. Nothing is ever sent to a server.

> **Important:** If you clear your browser data, your projects will be lost. Export your work regularly — the exported `.zip` includes an `editor.json` file that lets you re-import your project later.
